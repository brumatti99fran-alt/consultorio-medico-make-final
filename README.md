# Automatización de turnos médicos con Make

Automatización desarrollada con Google Forms, Google Sheets, OpenAI, Google Calendar, Airtable, Gmail y Make.

## Funcionamiento

1. El paciente completa Google Forms.
2. OpenAI valida la solicitud.
3. Google Calendar comprueba la disponibilidad.
4. Si está disponible, se crea el turno.
5. Si está ocupado, se solicita otro horario.
6. Los pedidos especiales pasan a intervención humana.
7. Airtable registra los resultados.
